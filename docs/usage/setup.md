# Setup

## Installation

The training and evaluation code can be installed locally, by simply cloning
and pip installing the repository:
` git clone https://github.com/asagilmore/dinov3d.git `
` cd dinov3d && pip install .`

We recommend using a virtual environment such as Conda.

There is also a docker image located at ghcr.io/asagilmore/dinov3d,
which can be used instead. Further details on docker usage can be found
[here](./docker.md)
